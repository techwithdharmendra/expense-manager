# ExpenseFlow – Offline Expense & Cashbook Manager

ExpenseFlow is a modern offline personal finance application designed to help users manage expenses, income, wallets, and customer cashbook records securely and efficiently.

The app works completely offline and keeps all financial data stored locally on the user's device.

---

# ✨ Features

## 💰 Expense & Income Management
- Add expenses, income, and transfers
- Organize transactions using categories & subcategories
- Add transaction notes
- Daily transaction history

---

## 📊 Smart Analytics
- Visual spending analysis
- Donut charts & category insights
- Monthly cashflow graphs
- Income vs expense comparison
- Financial overview dashboard

---

## 🏦 Multi-Account Wallet System
Manage multiple accounts including:
- Cash wallets
- Bank accounts
- Credit cards
- Savings accounts

Track balances in real-time with automatic calculations.

---

# 📒 Cashbook Feature (Leti-Deti)

Track who owes you money and whom you owe.

### Features:
- Customer-wise records
- "You Gave" & "You Got" entries
- Net balance calculation
- Customer transaction history
- Quick customer overview
- Settlement tracking

Perfect for:
- Shop owners
- Freelancers
- Small businesses
- Personal lending records
