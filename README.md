# ExpenseFlow – Offline Expense Manager

ExpenseFlow is a modern offline expense tracking application designed to help users manage personal finances easily and securely.

The app allows users to:
- Track expenses and income
- Manage multiple accounts/wallets
- Analyze spending with charts
- View transaction history
- Export and backup data
- Work completely offline

---

## ✨ Features

### 💰 Expense & Income Tracking
- Add expenses, income, and transfers
- Organize transactions using categories & subcategories
- Add notes to transactions

### 📊 Analytics Dashboard
- Visual spending analysis
- Donut charts & cashflow graphs
- Monthly statistics and trends
- Expense category overview

### 🏦 Multi-Account Support
Manage:
- Cash wallets
- Bank accounts
- Credit cards
- Savings accounts

### 📅 Transaction History
- Daily grouped history
- Fast transaction browsing
- Clear income/expense separation

### ⚙️ Customization
- Currency selection
- Indian number formatting
- Hide balance option
- Decimal & sign controls
- Month start customization

### 💾 Backup & Export
- Export transactions to CSV
- Backup data as JSON
- Restore backups anytime

### 🔒 Privacy First
- 100% offline
- No account required
- No cloud sync
- No ads
- No data collection

All data stays locally on the user's device.
